### 발견 후 수정한 초기화 오류

태블릿에서 브랜드 직접 링크로 새로고침할 때 ScrollTrigger refresh 중 `once` reveal이 제거되며 오류가 한 번 발생했습니다. `toggleActions: play none none none`으로 바꿔 재생은 반복하지 않고 refresh 목록을 유지하도록 수정했습니다. 이후 18개 직접 링크 조합과 상세 4페이지 재검사에서 새 error/warn 로그는 없었습니다. QA JSON에는 수정 전 오류 1건을 진단 기록으로 남겼습니다.

### 성능·접근성 확인 범위

- GSAP/Lenis ticker·update·refresh 구독과 해제 코드를 점검했습니다. 별도 중복 RAF, 중첩 핀, 큰 필터 애니메이션 없음.
- 이미지 박스가 높이를 확보하며 각 단계에서 레이아웃 높이를 바꾸지 않습니다. 큰 이미지의 will-change는 활성 핀에만 제한했습니다.
- 실제 제주 사진을 사용하는 현재 히어로는 종전 8.84MB 일반 바다 MP4를 요청하지 않습니다.
- OS reduced-motion 분기는 자동 검사에서 초기화 생략을 확인했고, 정적 콘텐츠 순서 및 CSS fallback을 점검했습니다.

### 검증하지 못한 항목

- 실제 iOS Safari·Android 기기에서의 터치 관성, 브라우저 주소창 높이 변화 및 저사양 GPU 성능.
- 실제 OS의 모션 줄이기 설정을 바꾸는 종단 간 브라우저 검사와 스크린리더 음성 탐색.
- DevTools Performance의 프레임 시간·GPU 메모리 계측, CPU/network throttling 및 Lighthouse 점수. 화면 관찰을 60fps 보증으로 해석하지 않습니다.
- 실제 PHP 8.2 런타임, 운영 서버, 외부 SMTP 발송. 현재 PHP 8.5.5에서 검사했으며 메일 수신 주소/SMTP 설정은 이번에 변경하지 않았습니다.
- 일부 공식 회사·제품 이미지 원본은 해상도가 제한되어 있습니다. 새로운 기업 촬영 이미지로 교체하는 작업은 이번 범위에 포함하지 않았습니다.

| 비공개 경로 | `.env`, 번역·공통 코드·vendor·문서·Composer 파일 직접 요청 차단 확인 |
| 문의 통합 검사 | 로컬 SMTP를 사용한 9개 시나리오 통과. 합성 메일 1건 수신, 실제 외부 메일 0건 |

SMTP 검사는 서버 검증 오류, 너무 빠른 요청, CSRF, 허니팟, 출력 이스케이프, 성공 후 리다이렉트, 토큰 재사용 방지, 중국어 오류 표시를 포함합니다. SMTP 인증정보가 없는 실제 미리보기에서는 전송 버튼이 비활성화되고 공식 이메일이 표시됩니다.

## 브라우저 검사

- 홈: 한국어·영어·중국어 각각 390, 430, 1440, 1920px 폭에서 레이아웃 확인. 데스크톱 높이 900/1080px, 모바일 844px.
- 상세 페이지: 3개 언어 × 8개 페이지를 390px 및 1440px에서 검사. 최종 검사에서 문서의 가로 넘침 없음.
- 모바일 중국어 홈의 문단 최소 너비로 인한 12px 넘침을 수정하고 재검사했습니다.

- 데스크톱 홈의 실제 ScrollTrigger pin wrapper 4개 확인. 모바일과 모션 최소화에서는 0개.

## 접근성과 점진적 향상

실제 HTML 텍스트, 건너뛰기 링크, 논리적 제목 구조, 이미지 대체 텍스트, 포커스 표시, 키보드 사용 가능한 native dialog/언어 선택기, 입력 label과 필드 오류 연결을 구현했습니다. 효과 적용 전 기본 문서에는 전체 콘텐츠가 표시됩니다. 모션 비활성화 시 순차 콘텐츠가 유지됩니다.

실제 스크린리더와 iOS Safari/Android Chrome 기기 검수, 브라우저 JavaScript 전체 비활성화 실행은 수행하지 않았습니다. DOM/소스 확인과 Chromium 브라우저 검수를 접근성 인증으로 표현하지 않습니다.

## 성능과 운영상 남은 확인

- WebP, 로컬 폰트/라이브러리, 지연 이미지 로딩, 이미지 크기 예약, 모바일/데이터 절약 시 영상 포스터, 화면 밖 영상 정지를 적용했습니다.
- 동영상은 14초 약 8.84MB이며 현재는 단일 MP4입니다. 실제 네트워크에서 측정한 Lighthouse/Core Web Vitals 수치는 없습니다.
- 실제 PHP 8.2 서버, Apache/Nginx 배포 구성, HTTPS 인증서, 운영 캐시/CDN, 외부 SMTP 발송·수신은 검증하지 않았습니다.
- 운영 도메인과 메일 인증정보는 제공되지 않았습니다. 로컬 실행은 완료했으며 공개 서버 배포는 하지 않았습니다.
- 번역 전문 감수, 개인정보 보유·삭제 운영 확정, 최신 브랜드 표기·연락처 확인은 운영 담당자가 수행해야 합니다.
