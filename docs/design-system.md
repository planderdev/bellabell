2026-10-20 교체 기준. 이 문서가 현재 디자인 시스템의 기준이며, 이전 개편 보고서의 팔레트·타이포·CSS 파일 목록보다 우선합니다.

## 원본과 생성

사용자 지정 원본: `C:/Users/pc/Downloads/BASE-UI` (1.8.0).

- `design-system/base-ui/tokens.json`: 파운데이션·시맨틱·타이포·반응형 데이터. 프로젝트 컨테이너 폭은 사용자 요청에 따라 `1620px`로 변경.
- `design-system/base-ui/components/`: 실제 사용하는 9개 원본 모듈. 기본 리셋, 버튼, 칩/필터, 카드/미디어, 아코디언, 입력, 선택 컨트롤, 모션, 접근성.

- 원본 Downloads 폴더는 수정하지 않음. 라이선스는 NOTICE와 폰트·아이콘 고지에 보존.

## 적용 토큰

라이트 테마 494개 토큰을 단일 `:root`에 선언합니다. `brand.css`, 추가 `:root` 패치, 런타임 스타일 주입은 사용하지 않습니다. 브랜드 색상은 원본 계산 함수에 `#00AF84`를 넣어 생성하며, 사용자 지정 전경색 `brand-on`은 소스의 `#FFFFFF`를 사용합니다. 컨테이너 `1620px`와 영문용 Raleway 폰트 스택도 소스에서 지정합니다. 그 밖의 토큰은 원본 값과 같습니다.

| 항목 | 현재 값 |
| --- | --- |
| Primary | `#00AF84` |
| Primary 배경의 글자·아이콘 | `#FFFFFF` — 사용자 지정 `brand-on` |
| 강조 글자 | `#008766` — BASE UI의 라이트 배경용 잉크 |
| 본문 | `#191F28` |
| 보조 글자 | `#6B7684` |
| 기본 배경 / 보조 배경 | `#FFFFFF` / `#F2F4F6` |
| 컨테이너 | 최대 1620px, 내부 여백 PC 24px / 모바일 16px |
| 제목 display-1 | PC 56/72px → 모바일 32/42px |
| 본문 | 16/24px, 읽기용 16/26px |
| 서체 | 영문 A–Z/a–z: Raleway / 한글·중문·숫자·문장부호: 기존 Pretendard 및 시스템 대체 서체 |
| 모서리 | xs 4, sm 8, md 12, lg 16, xl 24px |
| 컨트롤 | 기본 버튼 48px, 입력 52px, 모바일 칩 최소 44px |
| UI 전환 | 120 / 200 / 320ms, BASE UI 표준 easing |

상태색(성공·주의·오류)과 원자 팔레트는 BASE UI 값을 사용합니다. 원본 SVG 로고와 사진은 브랜드 자산이며 UI 토큰과 구분합니다.

Raleway는 로컬 WOFF2 가변 폰트(100–900)를 사용하며 `unicode-range`로 영문 알파벳에만 적용합니다. 히어로의 상단 eyebrow와 하단 caption은 템플릿·번역·스타일에서 제거했습니다.

사용자 지정 `#00AF84` / 흰색 조합의 명도 대비는 2.81:1로, WCAG AA 일반 텍스트 기준 4.5:1을 충족하지 않습니다. 이 조합을 접근성 통과로 표시하지 않으며, 자동 검사는 요청한 전경색의 일치와 흰 배경의 `brand-ink` 대비를 각각 확인합니다.

메인 페이지에서 디자인 요소로 사용하는 대형 타이포는 BASE UI 제목 토큰에 맞춰 축소하지 않습니다. `home.css`에 히어로 브랜드명(최대 244px), 철학 키워드(280px), 원물 번호(150px), 연구 단계(80px / 핀 구간 62px), 브랜드명(210px), 연혁 연도(240px), 마지막 파트너십 제목(88px)의 기존 유동 크기를 보존합니다. 낮은 PC 화면과 태블릿·모바일의 크기 조정도 함께 적용하며 일반 제목·본문·컨트롤은 토큰을 사용합니다.

## CSS 책임

공통: `tokens.css` → `ui.css` → `base.css` → `layout.css`.

메인에서 `home.css`, 서브페이지에서 `details.css` 하나만 추가합니다. 외부 Lenis/Swiper CSS는 공통 스타일보다 먼저 로드합니다.

- `base.css`: 문서 의미, 공통 타이포, 컨테이너, 텍스트 링크.
- `layout.css`: 헤더, 메뉴, 언어 선택, 푸터, 공용 연혁.
- `home.css`: 메인 구성·반응형·핀 활성 상태.
- `details.css`: 서브페이지 구성·반응형.

이전 `components.css`, `responsive.css`, `animations.css`, `home-motion.css`는 삭제했습니다. 기존 토큰 이름을 새 토큰으로 우회 연결하는 호환 별칭도 추가하지 않았습니다. 페이지 CSS에는 직접 작성한 HEX/RGB 색상이 없습니다.

## 기능 및 접근성

기존 PHP 라우팅, 3개 언어, 폼 필드/서버 검증, FAQ/소식 필터와 GSAP 5개 타임라인을 사용합니다. 폼·카드·칩·아코디언은 BASE UI 클래스 구조로 교체했습니다. UI 전체를 다시 초기화하는 BASE UI JS는 추가하지 않았습니다. 기존 기능의 이중 이벤트 등록을 피하기 위해 네이티브 컨트롤과 현재 JS가 동작을 담당합니다.

BASE UI 기본 소스의 포커스 제거 규칙을 프로젝트 소스에서 수정해 키보드 포커스 2px 링을 유지했습니다. 소스의 입력 `outline: none !important`도 해제했습니다. 모션 마스크 모서리는 토큰을 읽고, 모바일 간격보다 컸던 가로 진입 이동은 `space-12`로 변경했습니다.

타이포·간격은 BASE UI의 768–992px 유동 규칙을 사용합니다. 1024px 미만에서도 세로형 화면 또는 높이 600px 이상이면 핵심 5개 핀 시퀀스를 유지하고, 세로 배치와 짧은 스크롤 거리를 적용합니다. 높이 600px 미만인 가로형 화면만 일반 흐름과 브랜드 스와이프로 전환합니다. 세로형 폰은 주소창 높이 변화로 핀이 갑자기 해제되지 않습니다. 모바일은 네이티브 터치 스크롤을 사용합니다. 운영체제 reduced-motion 설정은 모든 핀을 해제하며 별도 테마·모션 버튼은 없습니다.
